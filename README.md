# pixel-art-lab

像素画研究仓。记录「怎么画」和「为什么这么画」——参数化画法、结构自检、失败案例复盘。

只放研究，不放内容运营数据。

## 为什么有这个仓

画一张像素画，最难的不是下手，是三件事：

1. **形对不对**——是不是这个物种，比例是不是这个比例
2. **动作对不对**——这个动作的可能性，结构上成不成立
3. **自己看不出来**——画的时候没有可靠的反馈，只能靠反复被打回

这三件事都不是"多画几张"能解决的。所以这个仓收的是方法、判据和工具，让每一次返工都留下可复用的结论。

## 两条原则

**先查证，再动笔。** 不知道这个动物的尾巴有几节、壳纹朝哪边散，画出来的东西一定被一眼看出来不对。参考不是"看着像"，是能量出比例和结构关系。

**把"像不像"变成可判定的事。** 眼睛会骗人，尤其是自己画的。能用数值判的就用数值判：连通域、对称度、混色率、肋的源点角度。
