# 案例解剖

## 一、海马（雄性育儿）

### 查证到的结构

- 体侧扁，躯干 10~12 节骨环，七棱形
- 头与躯干成直角；头顶有头冠（5 短棘）；管状长吻，口小无牙，吸食
- 背鳍 1 片，胸鳍 2 片；**无腹鳍、无尾鳍**
- 尾四棱、能卷，末端细，常卷成钩
- **育儿袋在雄性腹面、尾前**，开口朝下
- 游泳直立，靠背鳍高频摆动，是最慢的鱼之一
- 常用尾缠住海草固定

### 三个画错的点和改法

| 错法 | 为什么错 | 改法 |
|---|---|---|
| 尾巴从尾根就绕 1.5 圈 | 真海马尾细长下垂，只有末端一个小钩 | 尾长 ≈ 0.5×体高，末端 0.85 圈、半径 0.085×体高 |
| 背面画了眼睛和嘴 | 背面只有背脊沟、骨环、两侧背鳍、头冠 | 背视图不画眼嘴，不露白腹 |
| 吻画长 | 解剖图注明 very short snout | 吻长 0.17×体高 |

### 尾巴缠草：必须螺旋推进

缠两圈时，如果两圈的半径相同，会叠成一坨，看不出是绕上去的。

关键：**每绕一圈，沿草茎往下挪一个螺距**。

```
pitch = c * 0.105 * (ang / 2π)
```

加了螺距之后，两道圈才分开，才读得出"缠"。

另外，圈半径要跟着角色尺寸走（`sr = max(1.2, c*0.065)`），否则全景里的小海马尾巴不够长，缠不上那根细草，会悬空。

## 二、扇贝（开合）

### 查证到的结构

- 壳扇形，铰合线**平直**，两端有翼状突起（壳耳）
- 壳面有放射肋，肋到边缘把壳缘顶成**波浪**
- 单枚闭壳肌，分横纹肌（快）和平滑肌（慢）
- **张开是被动的**：铰合部的弹性韧带（abductin）把两壳撑开，肌肉放松就张着
- **闭合是主动的**：闭壳肌收缩，受惊一秒能合十几次
- 张开时外套膜边缘的帘子垂下，外缘一排宝蓝色眼点（几十到两百只）
- 游走：快速合壳，水从铰合两侧喷出，反作用力弹走
- 静止时右壳在下、左壳在上，开口朝上偏前

### 三个画错的点和改法

| 错法 | 为什么错 | 改法 |
|---|---|---|
| 斜俯视一整片扇面 | 看着像压印的花纹，不像活的 | 改侧视 V 形开口：下壳平放、内面朝上，上壳绕铰合点抬起 |
| **放射肋从椭圆中心发散** | 这是最容易被一眼看出的错。扇贝的肋像扇子骨，从**壳尾（铰合端）**散开 | 肋的极角以铰合点为原点：`ray = atan2(ly, lx)` |
| 改了源点还是看着像平行横线 | 侧视投影把壳压得很扁（`ry=0.34rx`），直接在未归一化的坐标里算极角，角度全挤在 ±90°，肋就退化成横线 | 两点：① 角度按椭圆归一化 `atan2(ly/ry, lx/rx)`；② 上壳的投影别太扁，`ry` 给到 `1.65×` 才立得起来 |
| 张开时两片壳对称分开 | 真实是下壳不动、上壳抬 | 下壳固定（0°），上壳 `lift = open*52°` |

### 动作怎么读出来

- 张开：慢，可持续几十秒（滤食）
- 合上：快，1 秒内十几次（受惊）
- 游走：合壳喷水 + 整体跃起，不是平滑移动

这决定了动画节奏：开要缓，合要狠，喷水要跳。
