# 踩坑清单

每条都对应一次真实的返工，不是"大概可能会错"。

## 坐标与对称

**画布宽度取偶数 → 左右永远差 1px。**
中心落在半像素上，镜像怎么调都不平。正/背面视图的画布宽必须取奇数，`cx = (w-1)//2`。

**镜像被认为"差不多就行"。**
判据要给数：左右面积比 0.9~1.1、重心偏移 <1.5%、镜像 IoU >0.88。低于这个就是没对齐，不是"风格"。

## 结构

**绕圈不加螺距 → 叠成一坨。**
绕多圈的东西（尾巴、藤蔓、绳子），每圈必须沿轴推进，否则看不出缠绕。

**压扁的投影里，极角必须归一化。**
椭圆被压扁后（比如侧视的壳），直接用 `atan2(y, x)` 算角度，角度会全挤在 ±90°，放射纹退化成平行线。要先按长短轴归一化：`atan2(y/ry, x/rx)`。

**肋/纹的源点放错。**
放射状纹路的原点必须在结构上正确的位置：扇贝在壳尾，车轮在轴心，羽毛在毛根。放错位置，纹路会变成"贴上去的图案"。

**把"看见的样子"当"结构的样子"。**
比如把两片贝壳都画成一整片扇形对夹，看起来像夹子。真实是下壳平放、上壳抬起。

## 分层与虚化

**远处的东西不淡化，前景就没有主次。**
远处角色按 0.40~0.55 的比例混进背景色；混得不够，画面一层平。

**混色用手调，不按背景色算。**
手调会偏色。用 `c' = c + (water(y)-c)*dim`，随高度自动对。

## 绘制流程

**角色画进场景时忘了描边。**
同一片海里有的有描边有的没有，观众立刻觉得不对。做法：角色先画到独立层 → 统一描边 → 再贴回场景，这样描边不会连带描到草上。

**描边色不统一。**
主角色 (40,78,118)、小角色 (44,70,100) 这种差别，单看没感觉，放一起就脏。所有同类角色用同一个描边色常量。

**灰稿四档 vs 三档混用。**
不同用途的灰阶档位要统一，同一片子里换档位，黑白段会显得脏。

## 验证

**只看"感觉像"就交付。**
至少跑一遍结构自检：连通域（有没有断肢）、贴边（有没有出框）、混色（网格内有没有半格颜色）、对称。

**看图工具不可用时直接交。**
没有视觉反馈时，必须用可量化的检查兜底，并且**明确告知对方"这版我没看过"**。不要假装确认过。
