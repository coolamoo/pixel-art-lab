# 画法方法论

## 一、先定像素密度，再定构图

一个格子在成片里占多少像素，决定了这张画能承载多少细节。

经验值（竖屏 1080×1920，画面区 864）：

| 逻辑画布 | 一格 | 适用 |
|---|---|---|
| 72×72 | 12px | 场景 + 中景角色（正片主用） |
| 72×72 | 15px | 单幕特写、需要看清细节时 |
| 48×48 | 18px | 单角色设定图、拼豆图纸 |

**同一个片子里不要混用。** 一格 12px 和一格 15px 放一起，观众说不上哪里怪，但会觉得"跳"。

## 二、分层：近实、中虚、远更虚

近实远虚不是模糊，是**减少信息量**：

- 近处：完整描边、完整配色、有高光和骨环这类结构线
- 中景：描边保留，配色降一档饱和度
- 远处：把颜色按比例混进背景水色（实测 0.40~0.55 就够虚），描边也可以跟着淡

混色公式（比手动调色稳）：

```
c' = c + (water(y) - c) * dim
```

`water(y)` 取该像素所在高度的背景色。这样远处的东西是"融进水里"，不是"套了个灰罩"。

## 三、比例要能量出来，不能凭感觉

每个角色先定一个基准量（比如"站高 40 格"），其余尺寸都由它推：

- 海马：站高 40 格 → 头冠 4 格、吻长 0.17×体高、尾长 ≈ 0.5×体高
- 扇贝：壳宽 32 格 → 壳耳 5 格、铰合点偏右 0.8×宽、开口角最大 45°

比例错了，画得再细也不像。

## 四、对称的坑：画布宽度取奇数

左右对称的正面/背面视图，画布宽必须是奇数，中心线取 `cx = (w-1)//2`。

偶数宽时中心落在半像素上，镜像永远差 1px，怎么调都调不平——这不是画功问题，是坐标问题。

## 五、动作要按结构来，不能按感觉来

一个动作合不合理，取决于结构：

- 海马尾能缠住草，是因为尾是四棱、能卷、末端有钩
- 扇贝能一张一合，是因为铰合部有弹性韧带（被动张开）+ 闭壳肌（主动闭合）——所以"张开"是慢的、持续的，"合上"是快的、突发的

画动作前先问：**这个动作是哪个结构在驱动？** 答不出来，动作就会画成"整体缩放"或者"整体旋转"，一眼假。

## 六、参考的用法

1. 先找 3~5 张同类参考（活体照片 > 手绘 > 卡通）
2. 从参考里只提取三样：**轮廓比例、结构分区、配色**
3. 不要在参考上描——像素画要重新组织成格点，描出来的边缘全是碎像素

## 七、每个角色一个参数化函数

不要一张张画。写成一个函数，用参数控制状态：

```python
seahorse(cells, pose, phase, pouch, look, flip)
scallop(cells, open_, phase, jet)
```

好处：改比例只改一个数；动作可以直接做插值（`open_` 从 0 到 1 就是开合动画）；一处修好，所有帧都对。
