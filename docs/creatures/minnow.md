# 小鱼

- 期号：003｜一条不肯顺流的小鱼
- 叙事：逆流而上，力气用错地方

## 结构要点
- 流线体，侧扁；鳍：背鳍 1、胸鳍 2、腹鳍 2、臀鳍 1、尾鳍 1
- 鳞片覆瓦状排列；侧线沿体侧中线
- 逆流时身体呈 S 形摆动，尾鳍发力

## 比例与参数
- 体长 : 体高 ≈ 3.4 : 1
- 尾鳍长 ≈ 体长 0.22；背鳍高 ≈ 体高 0.3
- 眼径 ≈ 头长 0.28

## 配色
背 `#4C7A8A` 深青、体侧 `#7FB0BE`、腹 `#DCE8E4` 近白
鳍半透明 `#A8C8CE`，描边 `#27424C`

## 画法要点
- 三层色带（背深、侧中、腹白）是鱼的基本体积感
- 鳍要透：用比体浅一档、并留缝
- 逆流姿态：头略上扬、尾摆幅大

## 踩坑
- 鳍画成实心色块 → 像塑料
- 眼睛画在正侧面中央 → 应略偏上、靠前
