# 招潮蟹

- 期号：018《潮水上来前》｜一只不肯松钳的招潮蟹
- 章句：道德经·知足不辱，知止不殆
- 叙事：举着大螯跟隔壁比，潮来了还不肯放

## 结构要点
- 雄蟹一螯极大（可达体宽 2 倍），另一螯小；雌蟹两螯都小
- 眼柄细长；甲壳梯形，前缘有齿
- 举螯是威吓/求偶动作，不是战斗

## 比例与参数
- 大螯长 ≈ 甲宽 1.8~2.2；小螯 ≈ 0.35
- 甲宽 : 甲长 ≈ 1.3 : 1
- 眼柄长 ≈ 甲长 0.35

## 配色
甲：橙红→深红过渡；大螯同色但更亮（视觉焦点）
（色表见 `ep018/claw_art.py` 的 `BIG` / `SMALL` / `ARM_BIG` 列表）

## 画法要点
- 大螯是全身焦点，占画面 1/3 都不夸张
- 螯的"齿"要画 3~4 个凸起，否则像夹子
- 举螯时身体会后仰，重心要稳，不然像飘着

## 踩坑
- 两只螯画一样大会失去物种特征
- 螯画太重会压垮身体比例，注意甲壳别缩太小
