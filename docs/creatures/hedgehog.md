# 刺猬

- 期号：002｜小刺猬的漂亮窝（另说：为一块石头吵一整天）
- 叙事：把窝堆得漂亮，反而累

## 结构要点
- 背部和体侧布满棘刺（约 5000 根），受惊时竖立并蜷成球
- 吻尖、耳小、四肢短，脚有五趾
- 刺是变形的毛，根白尖黑

## 比例与参数
- 体长 : 体高 ≈ 1.6 : 1（蜷起时 1 : 1）
- 刺长 ≈ 体长 0.12
- 吻长 ≈ 头长 0.35

## 配色
刺：根 `#D8CBB4`，中 `#8A7A62`，尖 `#3A3128`
体：脸 `#C8B294`，腹 `#E8DDC8`
鼻：`#2A2420`

## 画法要点
- 刺走向要一致（从头顶向后背、向下腹），乱刺会像毛球
- 刺用 2~3 段短线，尖端一像素深色
- 蜷球时刺向外放射，脸藏在下方露出一小块

## 踩坑
- 刺画成三角形密集排列 → 像仙人掌
- 全身刺 → 脸和腹要留软毛
