# 水黾

- 期号：009｜夫唯不争｜一只站在水面上不沉的水黾
- 叙事：不跟水较劲，所以浮得住

## 结构要点
- 中足、后足极长，向两侧摊开，靠表面张力站在水面
- 足端有疏水毛，压出水面的小凹坑（这是画面关键）
- 前足短，捕食用；体细长

## 比例与参数
- 足展 ≈ 体长 4.5；中足最长
- 体长 : 体宽 ≈ 5 : 1
- 水面凹坑直径 ≈ 足端 3 倍

## 配色
体 `#2E2A26` / 高光 `#5A544C`；足 `#3A342E`
水面 `#7FB6C4` / 亮边 `#D8EEF2` / 凹坑暗 `#4A7E8C`

## 画法要点
- 站立的三点支撑：中足、后足压在四个小凹坑上，凹坑要画出来
- 身体离水面有极小的距离，靠腿撑起——不是浮在水里
- 水面用一条亮边 + 倒影断线表示

## 踩坑
- 足画成接触水面 → 看起来像"浮"而不是"站"
- 凹坑不画 → 失去最关键的物理感
