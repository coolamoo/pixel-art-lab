# 蜗牛

- 期号：008｜重为轻根｜一只背着重壳慢慢走的蜗牛
- 叙事：壳重，但也是它能活下来的原因

## 结构要点
- 螺旋壳（多为右旋），壳口在体右侧；螺层数可数
- 腹足宽大，爬行时分泌黏液留下亮痕
- 两对触角：长的一对顶端有眼，短的一对司触觉

## 比例与参数
- 壳径 : 体长 ≈ 1 : 1.8；壳高 : 壳径 ≈ 0.75
- 螺层 3.5~4.5 圈；体螺层最大
- 触角长 ≈ 体长 0.3

## 配色
壳 `#B08A50` / 暗 `#7A5A32` / 高光 `#D8B878`；螺层缝 `#4A3420`
体 `#C8B49A` / 暗 `#9A8468`；黏液痕 `#E8E4D8`

## 画法要点
- 螺层缝必须画（2~3 条弧），否则是个球
- 壳口要朝侧下，露出一小段身体
- 触角顶端两点深色即眼，别画大

## 踩坑
- 壳的螺旋方向画反 → 与常见右旋不符
- 身体画太粗 → 像鼻涕虫顶着壳
