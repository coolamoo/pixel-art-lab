# 松鼠

- 期号：006｜一只把树洞塞满的松鼠（另说：囤了三个树洞，冬天还是饿）
- 叙事：囤得越多，越怕丢

## 结构要点
- 尾长近体长、蓬松上翘；后肢长于前肢，善跳
- 门齿终生生长；颊囊可鼓（部分种类）
- 坐姿：后肢蹲、前爪捧食、尾贴背

## 比例与参数
- 体长 : 尾长 ≈ 1 : 0.95
- 耳长 ≈ 头长 0.4；耳端有簇毛
- 后足长 ≈ 体长 0.28

## 配色
背 `#A8703C` / 腹 `#E8D6B8` / 尾深 `#7A4A24` + 高光 `#D8A468`
眼 `#2A1E16`

## 画法要点
- 尾巴是主角：要有三到四层毛束，末端散
- 捧食的前爪要画出"关节在里侧"
- 大尾的暗部压在后缘，才有体积

## 踩坑
- 尾画成一条粗线 → 像猫
- 尾和背同色同明度 → 分不开
