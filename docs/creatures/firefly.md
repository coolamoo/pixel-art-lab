# 萤火虫

- 期号：001｜一只太亮的萤火虫
- 封面色：黑底 + 一点黄绿
- 叙事：光太亮，反而先被看见

## 结构要点
- 发光器在腹部末 1~2 节，雌雄位置略异；光来自荧光素酶反应，冷光
- 鞘翅长、盖住腹部；前胸背板宽圆，常遮住头部
- 停息时鞘翅合拢，发光器仍透出光

## 比例与参数
- 体长 : 体宽 ≈ 3.2 : 1
- 发光器 ≈ 体长 0.12，位于尾端
- 光晕半径 ≈ 体长 0.6（软边，不必画成圆）

## 配色
体：深褐黑 `#2A2620`；鞘翅高光 `#4A4438`
发光器：核心 `#F6F2A0`，外圈 `#C8D66A` → `#6E8C3E` 透明衰减

## 画法要点
- 光要"打"在环境上：身体下缘、落脚点各有一层绿光，不然只是贴了个亮斑
- 发光器别画成圆心，要略偏
- 暗环境里，身体不能纯黑，留一档 `#2A2620` 才看得出轮廓

## 踩坑
- 光晕画成硬边圆 → 立刻像贴纸
- 全身高光 → 像塑料虫
