# 海龟/老龟

- 期号：020《一只走最后面的》｜压在最后上岸的老龟
- 章句：道德经·我有三宝：慈、俭、不敢为天下先

## 结构要点
- 背甲由盾片拼成（中央 5 枚椎盾 + 两侧 4 对肋盾 + 缘盾一圈）
- 鳍状肢：前肢长而桨状，后肢短圆；头不能缩回（海龟）
- 沙滩上爬行靠前肢划沙、后肢蹬

## 比例与参数
- 背甲长 : 宽 ≈ 1.35 : 1
- 前肢长 ≈ 甲长 0.75；后肢 ≈ 0.35
- 头长 ≈ 甲长 0.22

## 配色
壳：`base #54442C` / `plate #B69E66` / `seam #2C2418`
皮肤：`base #8A8066` / `dark #645C4A` / `hi #B0A484`
眼：`#201C18`

## 画法要点
- 盾片是海龟的身份证：椎盾一排、肋盾对称，缝要画满
- 甲缘一圈锯齿状缘盾，缺了就变乌龟
- 鳍肢末端要收尖，画圆了像海豹

## 踩坑
- 盾片画成大格子会像拼图；每片要有自己的弧
- 爬行时身体不能水平滑，要一前一后起伏
