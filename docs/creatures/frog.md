# 青蛙

- 期号：014《周行不殆》｜一只越长越不像自己的青蛙
- 章句：道德经·周行不殆
- 叙事：蝌蚪 → 长腿 → 上岸，形态一路变

## 结构要点（查证）
- 变态发育：蝌蚪（尾、无腿、外鳃）→ 长出后腿 → 长出前腿 → 尾吸收 → 上岸
- 陆生蛙：后腿远长于前腿，趾间有蹼；眼在头顶两侧突出；无尾
- 静息时后腿折叠成 Z 形，这是"能弹跳"的结构前提

## 比例与参数
- 主体尺寸按镜头定（中景约 22~28 格）
- 后腿长 ≈ 体长 1.1 倍，折叠后不超过体长
- 眼径 ≈ 头宽 0.22，眼距 ≈ 头宽 0.45

## 配色
`YEL #F8E74E` 腹部高光 · `BLD #D6CC98` 腹 · `G_HI #99F57C` · `G_MID #60B06C` · `G_BACK #448F55` · `FAR #347042` · `FOOT #1E4A32` · `WEB #96C48A`

## 画法要点
- 背部三段绿：亮→中→暗，沿体侧分层，不要平涂
- 蹼用半透明感的浅绿，比脚趾浅一档
- 眼要压在头顶轮廓线上，不能嵌在头中间

## 踩坑
- 腿画直了像四脚蛇；静息状态必须画出 Z 形折叠
- 趾数别省：前 4 后 5，画成 3 根会明显像卡通 frog 而不是写实蛙
