# 蝉

- 期号：004｜一只在土里待了六年的蝉
- 章句意境：长时间蛰伏，一朝出土
- 叙事：慢，但一出来就是整个夏天

## 结构要点
- 若虫土中生活多年，吸食树根汁液；羽化时爬出、蜕壳
- 成虫：头宽、复眼大而分列两侧，三只单眼在头顶成三角
- 翅膜质透明、翅脉清晰；雄虫腹基有发音器

## 比例与参数
- 体长 : 翅展 ≈ 1 : 1.9
- 头宽 ≈ 体宽 0.9；复眼径 ≈ 头宽 0.3
- 翅长 ≈ 体长 1.3

## 配色
体 `#5A4A32` / 高光 `#8A7450`；翅 `#E8F0EE` 透 + 脉 `#5A6A62`
眼 `#2A2622`；蜕壳 `#C8B48A` 半透明黄褐

## 画法要点
- 翅是关键：透、有脉、边缘一条细线
- 蜕壳要画成"空壳"——比虫体浅、半透、背面裂开一道缝
- 复眼在头两侧突出，别画成正面两只圆眼

## 踩坑
- 翅画实 → 像蛾
- 蜕壳画成实心 → 分不清是虫还是壳
