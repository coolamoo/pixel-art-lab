# 扇贝

- 期号：022《小扇贝》｜被浪卷进石缝反而吃着饭
- 章句：道德经·祸兮福之所倚，福兮祸之所伏

## 结构要点（查证）
- 壳扇形，铰合线**平直**，两端翼状突起（壳耳）；壳面放射肋，肋把壳缘顶成波浪
- 单枚闭壳肌（横纹肌快、平滑肌慢）
- **张开是被动的**：铰合部弹性韧带（abductin）撑开，肌肉放松就张着
- **闭合是主动的**：闭壳肌收缩，受惊一秒十几下
- 张开时外套膜帘子垂下，外缘一排宝蓝眼点（几十到两百只）
- 游走：快速合壳，水从铰合两侧喷出，反作用力弹走
- 静止时右壳在下、左壳在上，开口朝上偏前

## 比例与参数
- 壳宽 32 格为基准；侧视投影 `rx=0.95c`、`ry=0.34c`（下壳），上壳 `ry×1.65`
- 铰合点偏右 `0.80W`；壳耳长 5 格
- 开口角 `lift = open_×52°`（等合 0°）

## 配色
外面 `O_HI #CEAC9C` / `O_MID #A87C6C` / `O_LO #7C544C`，肋 `#5C3A36`，边 `#E8C8B6`
内面 `#FAF9F4` / 边 `#E6E2D6` / 最外 `#C6C0B2`
肉 `#EEE2CE`；外套膜 `#E2C4B0` / `#BE968C`；眼 `#262834`；铰合 `#2A2428`

## 画法要点
- **肋必须从壳尾（铰合端）发散**，像扇子骨；从椭圆中心散开会像压印花纹
- 压扁投影里极角要归一化：`atan2(ly/ry, lx/rx)`，否则角度全挤在 ±90°，肋退化成横线
- 张开是"下壳不动、上壳抬起"，不是两片对称分开

## 踩坑
- 斜俯视整片扇面 → 被指出不像
- 肋从中心发散 → 被画箭头纠正
- 上壳投影太扁（ry 没放大）→ 扇形立不起来，还是横线
