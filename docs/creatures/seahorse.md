# 海马

- 期号：021《海马爸爸》｜雄海马揣卵一整季
- 章句：道德经·大方无隅，大器晚成

## 结构要点（查证）
- 体侧扁，躯干 10~12 节骨环（七棱形）；**无腹鳍、无尾鳍**
- 头与躯干成直角；头冠 5 短棘；管状长吻，口小无牙
- 尾四棱、能卷，末端细，常卷成钩，用来缠草固定
- **育儿袋在雄性腹面、尾前**，开口朝下
- 直立游泳，靠背鳍高频摆动，是最慢的鱼之一

## 比例与参数
- 站高 40 格为基准：头冠 4 格、吻长 0.17×体高、尾长 ≈0.5×体高
- 尾末小钩：0.85 圈、半径 0.085×体高（不是整条绕圈）
- 体宽 ≈ 0.21×体高

## 配色
体 `(150,205,238)` · 高光 `(188,226,248)` · 暗 `(116,176,218)` · 骨环 `(66,120,170)` · 白腹 `(252,252,250)` · 橙鳍 `(246,168,70)` · 描边 `(40,78,118)`

## 画法要点
- 骨环是识别关键：躯干上一圈圈横线，间距均匀
- 白腹做成"胸口窄—袋处最鼓—尾根收窄"的透镜形
- 背面只画背脊沟 + 体环 + 两侧背鳍 + 头冠，**不画眼嘴、不露白腹**
- 缠草必须螺旋推进：`pitch = c*0.105*(ang/2π)`，否则两圈叠成一坨

## 踩坑
- 尾巴从尾根就绕 1.5 圈 → 被指出"海马的尾巴没有那么卷吧"
- 画布宽取偶数 → 正/背视图镜像永远差 1px
- 吻画长 → 解剖图注明 very short snout
- 小尺寸（20 格）时圈半径写死 1.7 → 尾巴不够长、缠不上细草
