# 寄居蟹

- 期号：016（同场景角色）
- 结构要点
- 腹部柔软不对称、螺旋状，藏在螺壳里；右螯大于左螯，用来堵壳口
- 步足露出壳口的两对最粗；眼在短柄上

## 比例与参数
- 螺壳长 ≈ 体长 1.6；壳口直径 ≈ 螯宽 1.2
- 露出部分只占整体 40%，其余是壳

## 配色
壳：`SHELL base #54442C` / `plate #B69E66` / `seam #2C2418`（取自 020 贝壳常量，同族）
体：橙红偏暗，与壳拉开

## 画法要点
- 壳的螺旋要能数出 3~4 圈，纹路沿螺旋走，不要画成同心圆
- 换壳是它的标志动作：壳口朝下、身体半露、螯护口
- 壳比身体重要，壳画对了就认得出

## 踩坑
- 壳画成"圆顶"就没有寄居蟹感；一定要有开口和螺旋
- 身体画太完整会像螃蟹背着壳
