# 蜘蛛

- 期号：005｜一只想把网织得很大的蜘蛛
- 叙事：网越大，窟窿越多

## 结构要点
- 八足，头胸部与腹部分离；八眼（排列为种征）
- 丝出自腹部丝腺，经纺器吐出
- 圆网：放射丝 + 螺旋丝，锚点固定在至少三处

## 比例与参数
- 头胸 : 腹 ≈ 1 : 1.5；足展 ≈ 体长 4
- 足分 7 节，膝节最明显的折角
- 网：放射丝 12~16 条，螺旋圈 8~12 圈，越外越疏

## 配色
体 `#3A3230` / 高光 `#6A5A50` / 腹部花纹 `#A8784C`
丝 `#DCE4E0`（半透，压暗处 `#9AAAA6`）

## 画法要点
- 足要"折"：每足两个明显折角（膝、胫）
- 网不能画成正圆——透视下是椭圆，且边缘不闭合
- 丝要断点：连续线会像铁丝

## 踩坑
- 足画直 → 像螃蟹
- 网过密 → 糊成一片，留 30% 空隙才透气
