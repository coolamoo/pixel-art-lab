# 蚂蚁

- 期号：007｜柔弱胜刚强｜一只搬不动就换个办法的蚂蚁
- 叙事：硬搬搬不动，绕个方向就成了

## 结构要点
- 三节体：头、胸（并胸腹节）、腹柄 + 后腹
- 六足，胫节有距；触角膝状（柄节 + 鞭节）
- 上颚发达，搬运时用上颚夹住

## 比例与参数
- 头 : 胸 : 腹 ≈ 1 : 1 : 1.4
- 足展 ≈ 体长 1.6；触角长 ≈ 体长 0.7
- 体长 8~12 格（中景）

## 配色
体 `#3A2A22` / 高光 `#6A4E3E` / 关节暗 `#1E1612`
腿 `#4A382C`

## 画法要点
- 三节体必须分得清：细腰（腹柄）是关键
- 触角画成"折线"（膝状），直触角像蚊子
- 六足朝向要错开，三条一组朝前、三条朝后

## 踩坑
- 腰画粗 → 变成甲虫
- 腿全朝同一侧 → 像飘着
